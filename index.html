Connections

Once saved, type any Jira ID (e.g. DOC-1234) in the chat and DocMap will fetch it automatically.

Required for private repos. Public repos work without a token.

Paste a GitHub file URL in the chat (e.g. github.com/…/analyzing-pipelines.dita) and DocMap will fetch the DITA content automatically.

Paste any Google Docs URL in the chat and DocMap will fetch the content automatically.

No setup needed for publicly shared documents.

For private docs: open the doc → Share → change to "Anyone with the link — Viewer".

Google OAuth support (for fully private docs) is planned for a future release.

Type or paste a full file path in the chat and DocMap will read it via the local proxy.

Supported: .txt .md .json .yaml .csv .xml .docx .pdf and most code file types.

.docx and .pdf require extra packages: npm install mammoth pdf-parse

Example paths:
C:\Users\You\Documents\spec.docx
/Users/you/Documents/release-notes.md
